# Khushii Trip Surprise 💗

A tiny, responsive, static invitation website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — the complete website
- `assets/pink-background.jpg` — your widescreen pink gingham background with strawberry, ribbons, and cat
- `assets/lace-card.png` — your transparent-edged lace invitation card with four pink bows
- `assets/thank-you-card.jpg` — your thank-you card artwork

## Preview on your computer
1. Extract this ZIP.
2. Open the `khushii-trip-surprise` folder.
3. Double-click `index.html` to open it in your browser.

No installation or build step is needed.

## Publish free with GitHub Pages
1. Sign in at https://github.com/ and create a **New repository** named `khushii-trip-surprise`.
2. Set it to **Public** (required for GitHub Free Pages).
3. Upload the contents of this folder to the repository's top level. Make sure `index.html` is at the top level and the `assets` folder is alongside it.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. The Pages section will show your public website URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/khushii-trip-surprise/`
